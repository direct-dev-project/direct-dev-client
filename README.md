# [Direct.dev] Client Libraries

[![License](https://img.shields.io/badge/license-Direct.dev%20Terms%20and%20Conditions-blue)](./LICENSE.md)

Welcome to the **direct-dev-client** repository!  
Here, you'll find our official libraries for seamless integrations with Direct.dev for popular Web3 clients.

## About

[Direct.dev] is an RPC read layer designed to optimize speed and resilience for Web3 applications.  
These client libraries are maintained and updated by the Direct.dev team to ensure the highest level of reliability and performance.

## Dependencies

We follow a dependency-free philosophy, ensuring that these libraries do not rely on unnecessary third-party packages.  
This results in a more secure, predictable, and stable supply chain.
